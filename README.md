# 离线赛车赛线与速度约束工具

这是一个**纯前端、无后端、可离线运行**的游戏调参工具，用于比较弯道行车线与给定二维质点模型下的速度上限和圈时。

技术栈：

- Svelte + TypeScript：工程、控制点和车辆参数编辑
- Three.js：俯视赛道、赛线、约束颜色和车辆代理动画
- mathjs：向量、叉积、平方根等几何/约束计算
- IndexedDB：浏览器本地保存工程
- Vitest：数值模型、边界和采样稳定性测试

## 启动

```bash
npm install
npm run dev
```

构建离线静态文件：

```bash
npm run build
npm run preview
```

检查和测试：

```bash
npm run check
npm test
```

构建产物位于 `dist/`，可直接由任意静态文件服务器离线打开。

## 内置样例

1. **直道接急弯**：开放路线，检验长直道加速、弯前制动传播和弯心曲率约束。
2. **闭合首尾环道**：闭合路线，使用周期性前向/后向传播，保证接缝速度一致。
3. **宽窄变化连续弯**：开放路线，验证不同赛道宽度下的边界投影和最小净空。

## 模型说明

车辆使用简化二维质点模型：

- 纵向加速：`a+`，由 `accel` 给出
- 纵向制动：`a-`，由 `brake` 给出正数
- 横向加速度上限：`v²κ ≤ lateralG`
- 车辆极速：`v ≤ maxSpeed`
- 开放路线：固定起点、终点速度
- 闭合路线：速度剖面周期一致，无固定起止速度

曲率不是在每个点独立给一个“最高速度”就结束，而是先计算局部可行速度：

```text
v_curvature(i) = sqrt(lateralG / κi)
v_local(i)     = min(maxSpeed, v_curvature(i))
```

然后进行传播：

```text
前向加速：v(i) ≤ sqrt(v(i-1)² + 2 · accel · ds)
后向制动：v(i) ≤ sqrt(v(i+1)² + 2 · brake · ds)
```

闭合路线会循环执行前向和后向传播直到收敛或达到迭代上限。右侧表格逐段显示：

- 段起点弧长和距离
- 入速/出速
- 段时间
- 当前入口速度实际受哪条约束限制：
  - 端点速度
  - 车辆极速
  - 横向曲率
  - 加速传播
  - 制动传播

段时间积分使用：

```text
Δt = 2 · ds / (v0 + v1)
```

## 边界检查

赛道由中心样条和逐控制点宽度生成。赛线重采样后投影到单调递增的赛道弧长线段上，检查：

```text
clearance = halfWidth - distanceToCenterline
```

任意采样点 `clearance < 0` 即判定赛线越界，并拒绝生成速度剖面。连续弯和闭合首尾处不只使用“空间最近点”，以避免投影到错误的另一条邻近赛道段。

## 采样稳定性

工具栏可以把采样数加密到当前的至少两倍（默认闭合环道为 480，加密到 960）。工具比较：

- 圈时相对误差
- 最高到达速度相对误差

测试阈值为 **0.5%**。Vitest 会对三个内置样例自动执行该检查。动画只作为辅助观察，圈时、约束和稳定性以数值计算与测试为准。

## 数据

- `保存`：写入浏览器 IndexedDB
- `打开`：从本地 IndexedDB 读取
- `导出 JSON` / 文件导入：便于团队成员离线交换调参工程
- 不向任何服务器发送数据
