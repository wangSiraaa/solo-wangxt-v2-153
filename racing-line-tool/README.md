# 赛车线 / 速度上限离线工具

面向关卡团队的**纯前端**调参工具：编辑赛道、在边界内优化赛车线、用二维质点模型求解速度上限并逐段分析圈时。**无后端**，工程保存在浏览器 IndexedDB。

> 模型为简化二维质点 + 恒定加/减速（可选摩擦圆），结果仅供游戏调参，不作车辆动力学依据。

## 运行

```bash
npm install
npm run dev        # 开发
npm run build      # 产物
npm test           # 数值验证（vitest，27 个用例）
npm run check      # svelte-check 类型检查
```

## 物理模型与约束求解

1. **几何（`src/lib/core/geometry.ts`）**：控制点 → 向心 Catmull-Rom 三次样条（系数由 mathjs `lusolve` 解 Vandermonde 方程）。位置、切法向、**曲率全部解析求值**，κ(s) 是确定的连续函数——这是采样加密后结果稳定的关键。
2. **曲率限速（`solver.ts`，mathjs 逐元素运算）**：`v ≤ sqrt(a_lat / |κ|)`，再被 `v_max` 封顶。
3. **前后向传播**：加速 `v[i+1]² ≤ v[i]² + 2·a_acc·ds`，制动 `v[i]² ≤ v[i+1]² + 2·a_brk·ds`，往返扫描至不动点（单调下降有下界，必收敛；闭合赛道环绕传播）。**不存在逐点独立给最高速度**——任何点只能被 曲率 / 加速 / 制动 / 极速 四条约束之一限制，求解后逐点标注（`constraint`）。
4. **圈时**：匀加速假设 `dt = 2·ds/(v_i + v_{i+1})`，逐段（控制点区间）汇总并给出主导约束（`report.ts`）。
5. **赛车线（`racingLine.ts`）**：256 个控制站的横向偏移（左正右负），站间周期 CR 插值；线路几何在固定 0.25 m 细网格建表，求解网格加密时几何不变。优化 = 拉普拉斯平滑 + 每步**钳制到边界内**（含 0.75 m 车身边际）；手动编辑同样强制钳制。

## 验证（`tests/`，画面动画只是辅助）

- 曲率：直线 κ≈0、样条圆 κ≈1/R、FD 曲率（mathjs）在精确圆上收敛；
- 求解：全场 `v ≤ v_曲率`、前后向不等式逐点成立（含闭合接缝）、存在被传播压低的点、直道 `topSpeed`/弯前 `braking`/弯心 `curvature` 标注、弯心速度 ≈ √(a_lat/κ)、分段耗时和 = 圈时；
- **加密稳定性**：三个样例（直道接急弯 / 闭合环路 / 宽窄变化）+ 优化线路，ds 2→1→0.5 圈时相对误差 < 2%；
- 线路：优化/钳制后全程在边界内、圈时不劣于中心线、峰值曲率不更高；
- 状态层：编辑 → 几何 → 求解 → 报表的派生链联动（runes 集成测试）。

## 界面

- **左上**：参数面板（车辆参数、ds、样例、线路优化、IndexedDB 工程存取）；
- **中**：2D 编辑器——拖动控点、双击加点、右键删点、滚轮缩放、空白拖拽平移、「编辑线路」模式下拖橙色手柄（自动钳制在边界内）、闭合首尾开关；
- **右**：Three.js 3D 视图——赛道条带、按速度着色的赛车线、车辆代理按求解速度剖面行驶（OrbitControls）；
- **下**：v-s 速度图（背景色带 = 激活约束，虚线 = 曲率上限）+ 逐段圈时表（主导约束与分布）+ 赛车线/中心线圈时对比。
